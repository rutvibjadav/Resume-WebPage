# Rutvi Jadav — Resume Website

## Project description

A simple, responsive resume website for Rutvi Jadav, a Computer Engineering student interested in web development, databases, and software development. The site presents education, technical skills, internship experience, projects, and contact placeholders in a professional, easy-to-scan layout.

## Objectives

- Build a professional online resume using semantic HTML5 and CSS3.
- Present academic and project experience clearly to internship and entry-level employers.
- Practice responsive layouts, accessible navigation, and consistent visual styling.

## Technologies used

- HTML5
- CSS3 (CSS Grid, Flexbox, custom properties, and media queries)

The resume page itself uses no JavaScript, frameworks, external libraries, or build tools.

## Features

- Responsive navigation with links to each resume section.
- About, education, skills, internship experience, projects, and contact sections.
- Modern deep teal, soft mint, and off-white color palette.
- Responsive cards and layouts for mobile, tablet, and desktop.
- Smooth in-page scrolling, hover states, and visible keyboard focus styles.
- Contact details are clearly marked as placeholders until actual details are supplied.

## Run locally

1. In VS Code, choose **File → Open Folder...** and select the `resume-website` folder.
2. In the Explorer panel, right-click `index.html` and choose **Reveal in File Explorer**. Double-click `index.html` there to open it in your default browser. You can also open the file directly in any browser.
3. For automatic refresh while editing, install the **Live Server** extension, right-click `index.html` in VS Code, and select **Open with Live Server**. Live Server is optional; the site works by opening `index.html` directly.

## Test responsiveness

- In a desktop browser, open Developer Tools and toggle the device toolbar.
- Check a phone-sized viewport (for example, 375 px), a tablet-sized viewport (for example, 768 px), and a desktop viewport (for example, 1280 px).
- Scroll through the page and test the navigation links, buttons, card layouts, and contact details at each size.
- Use the keyboard Tab key to check that links and buttons have visible focus indicators.

## Learning outcomes

- Structuring a multi-section page with semantic HTML elements.
- Connecting page navigation to section IDs with anchor links.
- Styling reusable cards and page layouts using CSS Grid and Flexbox.
- Creating responsive breakpoints and mobile-friendly layouts.
- Improving usability with readable contrast, keyboard focus indicators, and reduced-motion support.
